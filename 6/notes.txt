Problem 1 (Board Data Type):I implemented the Board data type by precomputing hamming, manhattan, and blankPos in the constructor. For isSolvable(), I used Inversions.count() on a 1D array of tiles in row-major order. The main issue was that Inversions.count() returns a long, not an int, which caused a compile error that I fixed by changing the variable type.

Problem 2 (Solver Data Type): I implemented the A* algorithm using a MinPQ of SearchNodes, where each node's priority is its Manhattan distance plus the number of moves. Once the goal board is found, I reconstructed the solution by walking back through previous references and pushing boards onto a LinkedStack.
