[Problem 1 (Compute Edit Distance)]

Goal: The goal of this program is to compute the minimum alignment cost between two input strings x and y using dynamic programming.Specifically, the program constructs a 2D table opt where each entry opt[i][j] represents the minimum cost of aligning the suffix of x starting at index i with the suffix of y starting at index j.

Approach: This program computes the minimum edit/alignment cost between two strings by solving all subproblems using dynamic programming and storing the results in a 2D table.

[Problem 2 (Recover Alignment)]

Goal: The goal of this program is to reconstruct an optimal alignment between two input strings x and y using a precomputed dynamic programming table opt.

Approach: This program reconstructs the optimal alignment by tracing decisions from the DP table, choosing the operation that led to the minimum cost at each step.
